# Architecture

## Goal

要件を満たすシステム全体の構成と責務を明確にする。

## Topics

- System context
- Components
- Responsibilities
- Data flow
- Storage
- External services
- Failure handling
- Deployment

## Complete when

- 主要コンポーネントが明確
- 責務境界が明確
- 主要なデータフローが明確
- 外部依存が明確
- Requirementsとの矛盾がない
- 主要な設計判断に `ADR-N` が振られ、対象の要件 ID が書かれている
- 要件 ID と、それを実現する設計（節）の対応表がある
