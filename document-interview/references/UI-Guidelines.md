# UI Guidelines

## Goal

見た目の方針、共通部品、品質基準とセルフチェックの手順を定め、各画面が同じ部品と同じ基準で作られるようにする。
画面の実装に入る前に、主要な操作の流れを人が確認できる状態にする。

## 品質方針

クオリティ基準としては Awwwards、Webby Awards、FWA で賞を獲れるくらいのクオリティを目指す。
実装者はセルフチェックを行い、そのクオリティ基準になるまで自分でクオリティアップを繰り返す。

文書では、この方針をプロジェクトの制約（描画方式、クライアント JS の可否、性能の上限、利用者の用途など）に合わせて解釈し、「何をもって受賞水準とするか」と「使わない表現」を明記する。
たとえば読み書きが中心のアプリでは、演出の量ではなく、タイポグラフィ、余白、状態の網羅、アクセシビリティ、速度といった完成度で到達する、と定める。

## Topics

- 品質目標とその解釈（上記の品質方針）
- デザインコンセプトとシグネチャー（その画面群だとわかる要素を3つ程度）
- **主要な操作シナリオと画面遷移**：「〜を作る」「〜に参加する」など主要な操作ごとに、どの画面から始まり、何手で完了するかをワイヤーフレーム程度で示す
- デザイントークン（色、書体、文字サイズ、余白、動き、ブレークポイント。ライト／ダーク）
- レイアウトと画面ごとの構成
- 共通部品（どの画面で使うか、受け取る値、状態）
- インタラクションと、網羅すべき状態（空、入力エラー、エラーページ、極端なデータ、件数の境界、権限による出し分け）
- アクセシビリティの基準（WCAG の適合レベル、`prefers-reduced-motion` など）
- 実装方針と予算（CSS、フォント、JS、外部リクエスト）
- 画面の文言の一覧（ボタン、空状態、エラー文。導線を変えたときに更新漏れを検索で見つけるため）
- 品質基準とセルフチェック（下記）
- 確認ツール（スクリーンショット、アクセシビリティの機械チェック）

## ID

検証できる規則（トークン、部品、状態、アクセシビリティ、予算、評価軸など）には `UI-N` を振る。
各規則には、根拠となる要件 ID（`FR` / `NFR`）または一次ドキュメントの ID（`C-NN`）を同じ行に書く（`ID-Rules.md`）。
画面の実装 Issue は、満たすべき `UI` を参照する。

## セルフチェックの要件

文書のセルフチェックの節は、少なくとも次を定める。

| 項目 | 定めること |
|---|---|
| 評価対象 | 画面単位のスクリーンショットに加え、**主要な操作シナリオをたどった結果**（手数、迷う箇所、導線の一貫性）を評価する |
| 評価軸と採点基準 | 軸ごとに、各点数が何を意味するか（例：6点＝崩れはないが汎用テンプレートの水準、8点＝…）を書く。合格ラインの点数だけが付き続けることを防ぐ |
| 比較対象 | 品質目標の水準にある参照サイトを3つ以上挙げ、採点時に並べて比べる |
| 独立採点 | 実装の文脈を持たない別のエージェント（サブエージェントなど）に、スクリーンショットと本書だけを渡して採点させる。**毎ラウンド必須**。自己採点と2点以上差がある軸は低い方を採用する |
| 合格条件 | 全軸が基準点以上、独立採点との差が1点以内、前ラウンドで挙げた改善点が解消済み、機械チェック（アクセシビリティ違反0件、予算内、`prefers-reduced-motion` で動きが止まる）を満たす |
| 繰り返しの上限 | 最大ラウンド数を決め、未達で上限に達したら、未達の軸・理由・次の打ち手を記録してユーザーの判断を仰ぐ |
| 記録 | ラウンドごとに採点、根拠、改善点、判定を記録する（例：`design/rounds/NN/review.md`） |
| 人の確認 | 少なくとも2回：①画面の実装前（操作シナリオとワイヤー）、②UI 基盤（トークンと共通部品）の完成時 |
| 実施のタイミング | UI 基盤の作業、各画面の作業（触れた画面と状態）、全画面の通し |

## Complete when

- 品質方針の解釈と、使わない表現が明記されている
- 主要な操作シナリオごとに画面遷移が示され、ユーザーが確認している
- デザイントークンと共通部品の一覧があり、各部品を使う画面が明確
- 網羅すべき状態が列挙されている
- アクセシビリティの基準と予算が数値で定まっている
- セルフチェックの評価軸・採点基準・比較対象・独立採点・合格条件・上限・記録方法が定まっている
- 検証できる規則に `UI-N` が振られ、根拠となる ID が書かれている
- Requirements の画面一覧と矛盾しない
