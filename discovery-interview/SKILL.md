プロジェクトの初期情報からプロジェクトoverviewを作成する。

## 手順

1. ユーザーの初期情報と、`spec/` 以下の一次ドキュメントを読む。
2. skill `grill-me-with-goal` を使い、Overview 作成に必要な不足情報を一問ずつ確認する。
3. 十分な情報が揃ったら `./docs/D1/PROJECT_OVERVIEW.md` を作成する。

## ID

ID の規則は `../document-interview/references/ID-Rules.md`（このスキルのディレクトリからの相対パス） に従う。

- Overview の各項目（主要機能、制約、前提、未決事項など）に `OV-NN` を振る。
- 一次ドキュメントに `C-NN` がある場合は、各 `OV-NN` の同じ行に由来の `C-NN` を書く。
- 一次ドキュメントに ID がない場合は、`C-NN` の振り方を提案し、ユーザーの承認を得てから一次ドキュメントに反映する。承認なしに一次ドキュメントを編集しない。
- 一次ドキュメントのどの記述にも対応しない `OV-NN` を作った場合は、由来に `追加` と書く。

## Overview に含めるもの

* 目的
* 対象ユーザー
* プラットフォーム
* 主要機能
* 想定規模
* 外部サービス
* 主な制約
* 既知の前提
* 未決事項

詳細設計には踏み込まない。
